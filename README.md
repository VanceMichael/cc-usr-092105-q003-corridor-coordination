# 跨区域大通道约束协同

描述跨区域通道项目中区段、资源条件与协同承诺的关系，并提供可运行的约束协同平台。

## 资料范围

`contracts/domain.schema.json` 约束交换资料的基本结构，`fixtures/domain.json` 提供一组不含真实个人信息的业务样例，`docs/domain.md` 说明领域对象与必须遵守的关系。读取模块只负责验证这些公开资料，不包含完整业务流程。

当前资料确认了以下事实：

- 大通道建设涉及用地、用海、用能等资源保障
- 法规制度与标准规则需要跨区域软联通
- 通道还要统筹网络、算力、数据等新型基础设施

## 约束协同平台

`src/coordination/` 把通道区段、方案版本、沿线城市与产业节点、用地用海用能条件、标准规则差异、算力通信配套和风险韧性要求组织成依赖图，支持：

- 部门承诺附带适用范围、期限与证据，口头赞同与正式放行严格区分
- 多方会签、批准后撤回、跨年计划调整、方案换版时重算受影响的审批和里程碑
- 相互冲突的标准进入专门裁决流程
- 敏感附件只向获授权地区开放
- 每次协调会输出三问报告：仅口头赞同的条件、已正式放行的条件、改变整体工期的堵点

机制说明见 `docs/platform.md`，演示场景见 `src/coordination/demo.py`。

## 校验方式

在仓库根目录运行 `python3 -m unittest discover -s tests -v`。测试会读取样例并核对领域标识、对象清单与规则清单是否完整，并验证平台的放行校验、事件重算、裁决流程与附件授权行为。
