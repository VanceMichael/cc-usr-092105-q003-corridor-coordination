# 跨区域大通道约束协同

描述跨区域通道项目中区段、资源条件与协同承诺的关系。

## 资料范围

`contracts/domain.schema.json` 约束交换资料的基本结构，`fixtures/domain.json` 提供一组不含真实个人信息的业务样例，`docs/domain.md` 说明领域对象与必须遵守的关系。读取模块只负责验证这些公开资料，不包含完整业务流程。

当前资料确认了以下事实：

- 大通道建设涉及用地、用海、用能等资源保障
- 法规制度与标准规则需要跨区域软联通
- 通道还要统筹网络、算力、数据等新型基础设施

## 约束协同平台

`src/` 在资料读取之外提供完整的约束协同平台：

- `model.py`：通道区段、方案版本、沿线城市与产业节点、用地用海用能条件、
  标准规则、算力通信配套、风险韧性要求、审批与里程碑，以及组织它们的依赖图
- `commitments.py`：部门承诺生命周期（口头赞同 → 正式放行 → 已撤回），
  承诺附带适用范围、期限与证据；视频发言永远不能作为正式放行依据
- `events.py` + `platform.py`：多方会签、批准后撤回、跨年计划调整、方案换版
  四类事件落地后，沿依赖图重新计算受影响的审批和里程碑
- `adjudication.py`：相互冲突的标准进入专门裁决流程，由裁决委员会裁定
- `access.py`：敏感附件只向获授权地区开放
- `report.py`：协调会三问——口头赞同、正式放行、改变整体工期的堵点

`fixtures/platform.json` 提供一组不含真实信息的协同场景样例，
设计说明见 `docs/platform.md`。

## 校验方式

在仓库根目录运行 `python3 -m unittest discover -s tests -v`。测试会读取样例并核对领域标识、对象清单与规则清单是否完整，并覆盖承诺生命周期、事件重算、裁决流程、附件授权与协调会报告。
