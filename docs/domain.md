# 领域约定

## 核心对象

- 通道区段
- 方案版本
- 沿线城市与产业节点
- 资源条件（用地、用海、用能）
- 标准规则差异
- 算力通信配套
- 风险韧性要求
- 部门承诺
- 项目堵点
- 里程碑
- 审批事项
- 标准裁决
- 敏感附件

## 已知规则

- 会议意见与正式批准必须区分
- 方案变化要传播到关联条件
- 每项解除结论必须保留证据来源
- 正式放行必须附带适用范围、期限与正式文件证据
- 视频发言不得计入正式放行
- 批准后撤回要触发受影响审批和里程碑的重算
- 相互冲突的标准进入专门裁决流程
- 敏感附件只向获授权地区开放

样例中的名称和编号仅用于说明字段关系，不能对应到现实中的个人、企业或业务记录。

## 平台实现

上述对象与规则在 `src/coordination/` 中实现为可运行的协同平台，机制对应关系见 `docs/platform.md`。
